# Freyja documentation

Start with the [repository quick start](../README.md#start), then choose the guide
for what you are doing.

| Guide | Covers |
| --- | --- |
| [Plugin setup](plugins.md) | Codex, Claude Code, MCP and alternate checkout locations |
| [CLI and local data](cli.md) | Commands, environment, browser setup and static exports |
| [Authoring](../plugin/skills/engaging-presentations/references/authoring.md) | Manifest, branding, TSX and SDK contracts |
| [Presentation craft](../plugin/skills/engaging-presentations/references/storycraft.md) | Concrete stories, progressive demos and visual review |
| [Architecture](architecture.md) | Source graph, service, player and metadata boundaries |
| [Contributing](../CONTRIBUTING.md) | Development and verification |
| [Security](../SECURITY.md) | Local trust model and private reporting |

The [shared presentation skill](../plugin/skills/engaging-presentations/SKILL.md)
connects the craft and authoring guides. Both agent plugins use it; authoring
instructions are maintained there rather than copied into each client package.
